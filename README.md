# Project Financial Planner

A modern financial planning web application built using HTML, CSS, and JavaScript.

## Features

- Monthly and yearly financial planning
- Income calculator
- Savings goal tracker
- Responsive modern UI
- Interactive planner controls
- Clean dashboard layout
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```bash
project-financial-planner/
│
├── index.html
├── style.css
└── script.js
```

## How It Works

Users can:
- Enter hourly wage
- Add work hours
- Set savings goals
- Calculate estimated financial progress
- Switch between monthly and yearly views

## Design Goals

This project focuses on:
- Clean user experience
- Responsive design
- Modern UI components
- Beginner-friendly JavaScript logic

## Future Improvements

- Add charts and analytics
- Add local storage support
- Add dark/light mode
- Add authentication
- Add downloadable reports
- Add financial insights using AI
